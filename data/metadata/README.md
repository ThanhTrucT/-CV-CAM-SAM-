# Metadata

`class_map.json` chứa VOC canonical order. Người 2 kiểm thứ tự CAM upstream trước khi sử dụng.
Sau xác minh, tạo `inventory.csv` (image_id, source, image_path, semantic_path, instance_path, width, height, status) và `image_tags.json` (image_id → class names). Chưa có tag/list thực tế trong scaffold.
